# SECTOR: KOPRULU — 게임 기획 통합 설계서 (v2 · 부대 서바이벌)

> v1(그리드 오토배틀러 로그라이크)에서 **지휘관 중심 부대 이동 + 호드 서바이벌** 구조로 전면 개편한 기획입니다.
> v1 문서는 git 히스토리(`fdcd823`)에서 확인할 수 있습니다.

## 1. 게임 개요
- **장르:** 탑다운 픽셀 부대 서바이벌 (Squad Horde Survival)
- **플랫폼:** Web (TypeScript + PixiJS v8 + Vite + React + Zustand), 데스크톱 + 모바일
- **한 줄 요약:** 플레이어는 **지휘관 1기**를 직접 움직이고, 지휘관을 중심으로 진형을 유지하며 따라오는 **부대원**이 자동으로 싸운다. 사방에서 끝없이 몰려오는 적 무리를 상대로 **10분을 버티고 최종 보스를 처치**하면 승리.
- **세계관:** 3개의 오리지널 진영(철갑 연합 / 적응 군체 / 성휘 교단)과 이들 모두를 위협하는 정체불명의 감염체 무리 "블라이트".

## 2. 한 판의 구조 (연속 생존 한 판)
```text
[타이틀] → [진영 선택] → [생존 런 10분 + 최종 보스] → [결과 화면] → 재도전
                              │
                              ├─ 이동: 지휘관만 조작 (WASD / 방향키 / 터치 조이스틱)
                              ├─ 전투: 부대원 자동 공격 (AUTO형 / 지휘관 방향형)
                              ├─ 성장: 경험치 결정 획득 → 레벨업 → 3택 1
                              └─ 종료: 지휘관 사망 = 즉시 패배 / 보스 처치 = 승리
```
- 별도의 전술 지도·상점·전투 준비 페이즈는 없음. 모든 성장은 런 도중 레벨업으로 이루어짐.
- 목표 플레이 타임: 한 판 10~12분.

## 3. 핵심 시스템

### ① 지휘관 (Commander)
- 플레이어가 직접 조작하는 유일한 유닛. **지휘관이 쓰러지면 즉시 패배.**
- 약한 자동 공격을 가지지만, 주 역할은 **이동 경로와 바라보는 방향으로 부대 전체를 지휘**하는 것.
- **바라보는 방향(Facing)**: 마지막 이동 방향. 정지해도 유지되며, "지휘관 방향형" 부대원의 사격 방향이 됨.
- 경험치 결정 흡수 반경(자석 반경)을 가짐.

### ② 분대 · 모듈 · 진화 (빌드 시스템)
빌드는 **분대 슬롯 4개 + 모듈 슬롯 4개 + 진화 레시피**로 구성된다. 진영당 분대 8종 중 4종만 고를 수 있어 "무엇을 넣지 않을지"가 핵심 결정이 된다.

| 요소 | 범위 | 규칙 |
|---|---|---|
| **분대** | 진영 전용 8종, 슬롯 4 | 같은 병종 부대원 묶음. **분대 레벨 = 정원 (Lv1 2명 → Lv5 6명)**, 레벨당 피해량 +12% |
| **모듈** | 세 진영 공용 8종, 슬롯 4 | 부대 전체 패시브. Lv1~5 |
| **진화** | 분대마다 1개 | **분대 Lv5 + 레시피 모듈 보유** 상태에서 엘리트가 떨어뜨린 **보급 상자**를 열면 상위 분대로 진화 |

- 부대원은 사망하면 영구 소멸하고 분대에 결원이 생긴다. 결원은 "증원" 선택지, 보급 드론(진화) 등으로만 채운다.
- 진형: 부대원은 지휘관 중심 동심원 링(6k칸)에 자동 배치. 전열(근접·탱커)은 바깥, 후열(원거리·지원)은 안쪽. 링 수는 총인원에 맞춰 자동 확장.
- 카드 표기: `◎ 자동 / ➤ 방향` · 공격 형태 · 전열/후열 + 한 줄 요약 + 진화 힌트.

**공용 모듈 8종**
| 모듈 | 레벨당 효과 |
|---|---|
| 고속 장전 | 공격 주기 -7% |
| 확장 탄창 | Lv1·3·5에 투사체·연쇄 +1 |
| 광역 탄두 | 폭발·원뿔·파동·장판 범위 +10% |
| 정밀 조준경 | 사거리 +8%, 치명타(2배) +5% |
| 강화 장갑 | 지휘관·부대원 최대 체력 +15% |
| 증폭 코어 | 피해량 +10% |
| 전술 기동 | 부대 이동속도 +6% |
| 수집 비콘 | 경험치·상자 흡수 반경 +20% |

### ③ 부대원 공격 방식
| 타기팅 | 동작 |
|---|---|
| **AUTO (◎ 자동)** | 사거리 안 표적을 스스로 조준 (가까운 적 / 체력 높은 적 우선). 근접 AUTO는 슬롯에서 리쉬 거리까지 돌진 후 복귀 |
| **FACING (➤ 방향)** | 지휘관이 바라보는 방향 원뿔 안의 적을 노리고, 없으면 정면 사격. 지휘관의 이동이 곧 조준 |

공격 형태: 사격 · 관통 · 근접(밀쳐내기) · 원뿔 · 파동 · 치유 · 연쇄(번개) · 설치(지뢰), 부가 효과로 화염 장판·다발 사격·엘리트 추가 피해·빈사 처형·피해 반사·자동 증원.

### ④ 진영과 지휘관
지휘관은 **진영당 3명 고정**(해금은 추후). 지휘관마다 시작 분대와 고유 패시브가 다르다.

**철갑 연합 (IRONCLAD)** — 진영 특성 **포진**: 지휘관이 0.5초 이상 정지하면 부대 공격력 +35%, 사거리 +25%.

| 지휘관 | 성격 | 시작 분대 | 패시브 |
|---|---|---|---|
| 현장 사령관 | 입문 · 사격 | 소총 분대 | 사격·관통형 분대 공격속도 +15% |
| 공병 대장 | 거점 · 설치 | 지뢰 공병 | 포진 대기 0.2초, 포진 중 지뢰·연쇄 피해 +40% |
| 돌격 지휘관 | 기동 · 전방 | 화염 분대 | 이동 중 방향형 분대 피해 +25%, 이동속도 +8% |

| 분대 | 역할 | + 모듈 → 진화 |
|---|---|---|
| 소총 분대 | ◎ 사격 · 후열 | 고속 장전 → **개틀링 분대** (초고속 연사) |
| 화염 분대 | ➤ 원뿔 · 전열 | 광역 탄두 → **소각 분대** (불길 장판) |
| 박격포 분대 | ➤ 범위 폭발 · 후열 | 확장 탄창 → **다연장 포대** (포탄 3발) |
| 저격 분대 | ◎ 체력 높은 적 우선 · 후열 | 정밀 조준경 → **처형자 분대** (관통 + 빈사 처형) |
| 방패 분대 | ◎ 근접 밀쳐내기 · 전열 | 강화 장갑 → **성벽 분대** (피해 60% 반사) |
| 지뢰 공병 | ◎ 지뢰 설치 · 후열 | 전술 기동 → **연쇄 지뢰 공병** (고속 지뢰 + 불길) |
| 수리 드론 | ◎ 치유 · 후열 | 수집 비콘 → **보급 드론** (14초마다 결원 1명 증원) |
| 테슬라 포탑병 | ◎ 연쇄 번개 · 후열 | 증폭 코어 → **폭풍 포대** (6연쇄) |

**적응 군체 (HIVE)** · **성휘 교단 (LUMEN)**: 현재 4종 프로토타입(지휘관 1명). 철갑 연합 검증 후 8종·지휘관 3명으로 확장.
- 적응 군체 특성 **점액 자취**: 지휘관이 지나간 자리 점액 위 아군 공격속도 +30%·이동속도 +20%, 적 이동속도 -30%
- 성휘 교단 특성 **광휘 보호막**: 2.5초간 피해가 없으면 보호막이 초당 25% 재생

### ⑤ 적 (블라이트 무리)
- 화면 밖 원형 경계에서 지속 스폰, 지휘관을 향해 직진하며 서로 밀어냄(군집 분리). 부대원·지휘관에 닿으면 접촉 피해.
- 시간이 지날수록 스폰 밀도·종류·체력 증가 (`src/data/survivor_waves.json`).
- 적 종류: 진드기(빠르고 약함) · 기어충(표준) · 부풀이(느리고 단단함) · 파쇄충(대형 근접) · 엘리트(강화 개체) · **최종 보스 "블라이트 모체"(9:30 등장)**
- 이벤트: 1:30부터 약 1분 간격 엘리트 투입(보급 상자 드롭), 5분·8:40 "포위"(지휘관 주변 원형으로 대량 스폰).
- 지휘관에서 너무 멀어진 적은 진행 방향 앞쪽으로 재배치 → 밀도 유지.

### ⑥ 성장 (레벨업 3택 1 + 보급 상자)
- 적 처치 → 경험치 결정 → 레벨업 시 일시정지 후 3택 1: **신규 분대 / 분대 레벨업 / 신규 모듈 / 모듈 레벨업 / 증원**(결원 2명 이상), 선택지가 없으면 긴급 보급.
- 보유 분대의 진화 모듈은 등장 확률이 높다.
- **보급 상자**: 엘리트 처치 시 드롭(1:30부터 약 1분 간격). 열면 진화 가능한 분대를 진화시키고, 없으면 무작위 강화 1개.

### ⑦ 승패
- **패배:** 지휘관 체력 0 → 즉시 결과 화면.
- **승리:** 9:30 등장하는 최종 보스 처치. (10:00 이후에도 보스가 살아있으면 계속 진행)
- 결과 화면: 생존 시간, 처치 수, 도달 레벨, 남은 부대원.

## 4. 조작
- **데스크톱:** WASD / 방향키 이동, `Space`/`P` 일시정지
- **모바일:** 화면 아무 곳이나 터치 후 드래그 → 플로팅 가상 조이스틱 (세로 화면은 캔버스 아래 조작 패드)

## 5. 픽셀 아트 규칙
- 가상 해상도 `640x360`, `scaleMode: 'nearest'`, 좌표 `Math.round()` 정수화
- 유닛 스프라이트 `12x12 px` 기본(대형은 스케일 1.5~2.5배), 1px 어두운 외곽선, 진영 3색 팔레트로 재채색
- 모든 스프라이트는 오리지널 도트 맵(`src/core/SurvivorSprites.ts`)에서 런타임 생성
