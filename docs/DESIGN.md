# SECTOR: KOPRULU — 게임 기획 및 웹 아키텍처 통합 설계서

## 1. 게임 개요 (Game Overview)
- **가제:** SECTOR: KOPRULU (섹터: 코프룰루) / PIXEL FRONTIER (픽셀 프론티어)
- **장르:** 픽셀 전술 오토배틀러 로그라이크 (Tactical Grid Auto-Battler Roguelike)
- **플랫폼:** Web (TypeScript + PixiJS v8 + Vite)
- **핵심 컨셉:** 스타크래프트의 3종족 비대칭 전투를 그리드 오토배틀러로 재해석. 종족별 기본 일꾼 1기로 시작해 스테이지를 돌파하며 병력을 모집·강화하고, 진형 그리드를 `3x3(9기)` → `4x4(16기)` → `5x5(25기)`로 확장해 후반부 대규모 물량전을 완성하는 게임.

---

## 2. 핵심 게임 시스템 (Core Systems)

### ① 종족별 스타팅 및 고유 특성 (3종족 비대칭)
- **테란 (Terran):**
  - 스타팅 유닛: SCV 1기 (근접 공격, 아군 메카닉 수리)
  - 종족 특성 **[전술 개조 / 애드온]**: 생체(BIO) 유닛은 체력을 소모해 공격 속도를 높이는 '스팀팩' 시너지 발동, 메카닉(MECH) 유닛은 공성 모드(사거리 증가/이동 불가) 등 전술 스탠스 전환.
- **저그 (Zerg):**
  - 스타팅 유닛: 드론 1기 (근접 공격, 적 처치 시 체력 소량 회복)
  - 종족 특성 **[군단 변이 / 점막]**: 동일/하위 유닛을 진화·변태시켜 상위 개체 생성. 전투 시작 시 아군 진영 바닥에 '점막(Creep)'이 생성되어 저그 유닛의 이동 및 공격 속도 증가.
- **프로토스 (Protoss):**
  - 스타팅 유닛: 프로브 1기 (근접 공격, 플라즈마 실드 보유)
  - 종족 특성 **[플라즈마 실드 / 차원 관문]**: 모든 유닛이 전투 종료 후 자동 회복되는 실드 보유. 전투 중/매 턴 대기열 병력을 전장에 즉시 소환하는 '차원 소환' 기믹 보유.

### ② 그리드 확장 시스템 (`3x3` → `4x4` → `5x5`)
- **Act 1 (`3x3` / 최대 9기):** 소규모 국지전. 근접 탱커(파이어뱃, 질럿, 저글링)와 원거리 딜러(마린, 드라군, 히드라)의 기본 전열·후열 배치.
- **Act 2 (`4x4` / 최대 16기):** 중규모 교전. 시즈 탱크, 러커, 리버 등 광역 스플래시 유닛과 메딕/사이언스 베슬 등 서포터 시너지 본격화.
- **Act 3 (`5x5` / 최대 25기):** 총력전(대규모 물량전). 배틀크루저, 울트라리스크, 캐리어 등 최종 티어 대형 유닛이 합류하며 아군 25기 vs 적군 25기 이상이 맞붙는 대규모 교전.

### ③ 스테이지 전투 규칙 (3가지 모드)
- **적 몰살 (Annihilation):** 제한 시간 내 적의 모든 유닛과 건물을 섬멸.
- **거점 버티기 (Defense):** 제한 시간(예: 30초) 동안 사방에서 몰려오는 적 웨이브로부터 아군 핵심 건물(커맨드센터/해처리/넥서스)을 방어.
- **적진 돌파 (Breakthrough):** 적진 최후방에 배치된 '핵심 목표물(사이오닉 분열기, 오버마인드 촉수 등)'을 파괴하면 남은 적 병력과 무관하게 즉시 승리.

### ④ 메뉴 및 전체 게임 루프
```text
[타이틀 화면]
 ├── 새 게임 (종족 선택: 테란 / 저그 / 프로토스)
 ├── 병영/도감 (해금 유닛, 유물, 적 정보 확인)
 └── 설정 (해상도, 사운드, 전투 배속 1x / 2x / 4x)
        │
        ▼
[전술 지도 (노드 선택)] ── 3갈래 경로 선택 (전투 / 보급품·유물 / 정비소·강화)
        │
        ▼
[전투 준비 페이즈] ── 그리드(3x3~5x5) 드래그 앤 드롭 배치, 상점 병력 모집, 시너지 확인
        │
        ▼
[자동 전투 페이즈] ── 실시간 오토배틀 진행 + 지휘관 액티브 스킬(스캔/핵, 다크스웜, 스톰) 1회 개입
        │
        ▼
[전투 보상] ── 광물(골드) 획득 + 신규 유닛 드래프트(3택 1) 또는 유물 선택
```

## 3. 픽셀 아트 제작 및 리소스 파이프라인

### ① 해상도 및 스프라이트 규격
- **기준 타일 크기:** `32x32 px` (그리드 1칸 기준)
- **유닛 스프라이트 규격:**
  - 소형 유닛 (일꾼, 마린, 저글링, 질럿): `24x24 px` ~ `32x32 px`
  - 중형 유닛 (시즈 탱크, 히드라, 드라군): `32x32 px` ~ `48x48 px`
  - 대형 유닛 (배틀크루저, 울트라리스크, 캐리어): `64x64 px` (그리드 1칸을 점유하되 렌더링 레이어에서 위쪽으로 돌출되어 웅장함 표현)
- **시인성 규칙:** 어두운 저채도 배경 타일 + 유닛 어두운 단색 외곽선(Dark Outline) + 발밑 팀 컬러 링(파랑/빨강) 및 미니 체력바 배치.

### ② 애니메이션 프레임 규칙 (공수 최적화)
- **유닛당 총 8~10프레임 제한:** Idle(2f) + Move(2~4f) + Attack(2~3f) + Die(1~2f, 공용 폭발/혈흔 이펙트 합성)
- **방향 처리:** 좌/우 반전(Flip X)만 사용하여 2방향으로 통일.

### ③ 단계별 제작 파이프라인
1. **1단계 (프로토타입 플레이스홀더):** 코드로 32x32 단색 도형+이니셜 텍스처를 동적 생성하여 전투 로직부터 구현.
2. **2단계 (AI 원화 생성 및 도트 정제):** 로컬 ComfyUI(FLUX + Pixel Art LoRA)로 생성 후 Aseprite에서 Nearest Neighbor 축소(32x32/64x64) 및 종족별 고정 16~32색 팔레트 적용.
3. **3단계 (아틀라스 자동 패킹):** `free-tex-packer-cli`로 종족별 스프라이트 시트(`.png` + `.json`) 일괄 빌드.

## 4. 개발 로드맵 (GitHub Milestones)
- **Milestone 1 (`feat/grid-core`):** Vite + TS + PixiJS v8 초기 세팅, 픽셀 퍼펙트 캔버스, `3x3~5x5` 그리드 렌더링 및 드래그 앤 드롭 배치.
- **Milestone 2 (`feat/combat-engine`):** 일꾼(SCV, 드론, 프로브) 및 1티어 유닛 데이터 정의, 헤드리스 전투 루프(탐색·이동·공격·사망) 구현.
- **Milestone 3 (`feat/roguelike-loop`):** 종족 선택, 3택 1 드래프트 상점, 그리드 확장 이벤트, 3가지 스테이지 모드(적 몰살, 거점 버티기, 적진 돌파) 구현.
- **Milestone 4 (`feat/pixel-polish`):** 플레이스홀더를 실제 픽셀 아틀라스로 교체, 종족별 고유 기믹(스팀팩, 점막, 실드) 및 사운드 적용.
