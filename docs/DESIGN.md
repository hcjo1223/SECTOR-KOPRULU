# SECTOR: KOPRULU — 게임 기획 통합 설계서 (v2 · 부대 서바이벌)

> v1(그리드 오토배틀러 로그라이크)에서 **지휘관 중심 부대 이동 + 호드 서바이벌** 구조로 전면 개편한 기획입니다.
> v1 문서는 git 히스토리(`fdcd823`)에서 확인할 수 있습니다.

## 1. 게임 개요
- **장르:** 탑다운 픽셀 부대 서바이벌 (Squad Horde Survival)
- **플랫폼:** Web (TypeScript + PixiJS v8 + Vite + React + Zustand), 데스크톱 + 모바일
- **한 줄 요약:** 플레이어는 **지휘관 1기**를 직접 움직이고, 지휘관을 중심으로 진형을 유지하며 따라오는 **부대원**이 자동으로 싸운다. 사방에서 끝없이 몰려오는 적 무리를 상대로 **10분을 버티고 최종 보스를 처치**하면 승리.
- **세계관:** 3개의 오리지널 진영(철갑 연합 / 적응 군체 / 성휘 교단)과 이들 모두를 위협하는 정체불명의 감염체 무리 "블라이트".

## 2. 한 판의 구조 (연속 생존 한 판)
```text
[타이틀] → [진영 선택] → [생존 런 10분 + 최종 보스] → [결과 화면] → 재도전
                              │
                              ├─ 이동: 지휘관만 조작 (WASD / 방향키 / 터치 조이스틱)
                              ├─ 전투: 부대원 자동 공격 (AUTO형 / 지휘관 방향형)
                              ├─ 성장: 경험치 결정 획득 → 레벨업 → 3택 1
                              └─ 종료: 지휘관 사망 = 즉시 패배 / 보스 처치 = 승리
```
- 별도의 전술 지도·상점·전투 준비 페이즈는 없음. 모든 성장은 런 도중 레벨업으로 이루어짐.
- 목표 플레이 타임: 한 판 10~12분.

## 3. 핵심 시스템

### ① 지휘관 (Commander)
- 플레이어가 직접 조작하는 유일한 유닛. **지휘관이 쓰러지면 즉시 패배.**
- 약한 자동 공격을 가지지만, 주 역할은 **이동 경로와 바라보는 방향으로 부대 전체를 지휘**하는 것.
- **바라보는 방향(Facing)**: 마지막 이동 방향. 정지해도 유지되며, "지휘관 방향형" 부대원의 사격 방향이 됨.
- 경험치 결정 흡수 반경(자석 반경)을 가짐.

### ② 부대 진형 (Formation)
- 부대원은 지휘관 기준 **상대 좌표 슬롯**으로 스프링처럼 따라옴. 멈추면 대형을 갖추고, 이동 중에는 살짝 늘어지며 추종.
- 슬롯은 동심원 링 구조: 1링 6칸 → 2링 +12칸 → 3링 +18칸 (최대 36기). 런 시작 시 1링만 개방.
- **배치 규칙:** `BACK` 역할(원거리·지원)은 안쪽 링, `FRONT` 역할(근접·탱커)은 바깥쪽 링에 자동 배정 → 부대원이 자연스럽게 **지휘관을 감싸는 방벽**이 됨.
- 적은 부대원과 충돌하므로, 바깥 링의 탱커가 실제로 적을 막아줌.
- **부대원은 사망하면 영구 소멸.** 빈 슬롯은 남은 부대원이 재정렬해 메우고, 레벨업 "신규 합류"로만 다시 채울 수 있음.

### ③ 부대원 공격 방식 (2가지 타기팅)
| 타기팅 | 동작 | 대표 유닛 |
|---|---|---|
| **AUTO (완전 자동)** | 사거리 안의 가장 가까운 적을 스스로 찾아 공격. 근접 AUTO는 슬롯에서 일정 거리(리쉬)까지 돌진했다 복귀 | 소총병, 갈퀴충, 수호 기사 |
| **FACING (지휘관 방향)** | 지휘관이 바라보는 방향의 원뿔 안에서 표적을 찾고, 없으면 그 방향으로 정면 사격. 화력은 강하지만 **지휘관의 이동/방향 조작이 곧 조준** | 화염 방사병, 산성 분사체, 광선 창병 |

공격 형태: `PROJECTILE`(단발/스플래시), `PIERCE`(관통), `MELEE`(근접), `CONE`(원뿔 광역), `PULSE`(자기 중심 광역), `HEAL`(아군 치유)

### ④ 진영 (오리지널 3진영)
| 진영 | 콘셉트 | 진영 특성 |
|---|---|---|
| **철갑 연합 (IRONCLAD)** | 중장갑 인간 보병·보행 병기 | **포진**: 지휘관이 0.5초 이상 정지하면 부대 전체 공격력 +35%, 사거리 +25%. 움직일지 멈출지가 핵심 선택 |
| **적응 군체 (HIVE)** | 진화하는 생체 무리 | **점액 자취**: 지휘관이 지나간 자리에 점액이 남음. 점액 위 아군 공격속도 +30%·이동속도 +20%, 적 이동속도 -30% |
| **성휘 교단 (LUMEN)** | 결정체 갑주의 사이오닉 기사단 | **광휘 보호막**: 모든 부대원·지휘관이 보호막 보유. 2.5초간 피해를 받지 않으면 초당 25%씩 재생 |

진영별 부대원 풀 (각 4종):
- **철갑 연합:** 소총병(AUTO·투사체) · 화염 방사병(FACING·원뿔) · 박격 보행기(FACING·스플래시) · 수리 드론(AUTO·치유)
- **적응 군체:** 갈퀴충(AUTO·근접) · 가시 투척충(AUTO·투사체) · 산성 분사체(FACING·원뿔) · 껍질 갑충(AUTO·근접 탱커)
- **성휘 교단:** 수호 기사(AUTO·근접) · 프리즘 포대(AUTO·투사체) · 광선 창병(FACING·관통) · 공명 구체(AUTO·펄스)

### ⑤ 적 (블라이트 무리)
- 화면 밖 원형 경계에서 지속 스폰, 지휘관을 향해 직진하며 서로 밀어냄(군집 분리). 부대원·지휘관에 닿으면 접촉 피해.
- 시간이 지날수록 스폰 밀도·종류·체력 증가 (`src/data/survivor_waves.json`).
- 적 종류: 진드기(빠르고 약함) · 기어충(표준) · 부풀이(느리고 단단함) · 파쇄충(대형 근접) · 엘리트(강화 개체) · **최종 보스 "블라이트 모체"(9:30 등장)**
- 이벤트: 2·4·6·8분 엘리트 투입, 5분 "포위"(지휘관 주변 원형으로 대량 스폰).
- 지휘관에서 너무 멀어진 적은 진행 방향 앞쪽으로 재배치 → 밀도 유지.

### ⑥ 성장 (레벨업 3택 1)
- 적 처치 시 경험치 결정 드롭 → 지휘관 자석 반경 안에서 흡수 → 레벨업 시 일시정지 후 3택 1.
| 선택지 | 효과 |
|---|---|
| **신규 합류** | 진영 풀의 부대원 1기가 빈 슬롯에 합류 (빈 슬롯이 있을 때만) |
| **부대 강화** | 해당 유닛 종류 전체 레벨 +1 (최대 Lv5, 피해량 +25%/공격주기 -8% 누적) |
| **진형 확장** | 다음 링 개방 (6 → 18 → 36 슬롯) |
| **지휘관 강화** | 최대 체력 / 이동속도 / 자석 반경 / 재생 중 1개 |
| **긴급 보급** | 부대 전원 + 지휘관 체력 완전 회복 (다른 선택지가 부족할 때 등장) |

### ⑦ 승패
- **패배:** 지휘관 체력 0 → 즉시 결과 화면.
- **승리:** 9:30 등장하는 최종 보스 처치. (10:00 이후에도 보스가 살아있으면 계속 진행)
- 결과 화면: 생존 시간, 처치 수, 도달 레벨, 남은 부대원.

## 4. 조작
- **데스크톱:** WASD / 방향키 이동, `Space`/`P` 일시정지
- **모바일:** 화면 아무 곳이나 터치 후 드래그 → 플로팅 가상 조이스틱 (세로 화면은 캔버스 아래 조작 패드)

## 5. 픽셀 아트 규칙
- 가상 해상도 `640x360`, `scaleMode: 'nearest'`, 좌표 `Math.round()` 정수화
- 유닛 스프라이트 `12x12 px` 기본(대형은 스케일 1.5~2.5배), 1px 어두운 외곽선, 진영 3색 팔레트로 재채색
- 모든 스프라이트는 오리지널 도트 맵(`src/core/SurvivorSprites.ts`)에서 런타임 생성
